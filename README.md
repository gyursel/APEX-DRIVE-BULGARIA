# APEX DRIVE BULGARIA — уебсайт + админ панел

Съществуващият графитено-червен уеб дизайн е запазен. Изходният код съдържа админ панел на **`/admin`** за изображения, продукти, цени, наличности, промоции, категории, навигация, работно време, контакти, редакция на секциите, чернови/публикуване и история. Цените са в евро.

Сайтът чете **само публикуваното** съдържание; редакциите първо се запазват като чернова. Съдържанието се съхранява в Cloudflare D1, снимките в R2. Достъпът разчита на удостоверяване на собственика от ChatGPT Sites и сървърна променлива `CMS_OWNER_EMAIL`. Нужни са binding-и `DB` (D1) и `BUCKET` (R2).

Разгръщане в съвместима среда: инсталирайте зависимостите, генерирайте приложението (`npm run build`), настройте D1/R2, приложете SQL миграцията от `drizzle/` и задайте `CMS_OWNER_EMAIL` **като сървърна конфигурация**, преди да посетите `/admin`. Не излагайте админ API без платформеното удостоверяване.

Подробности: `docs/ADMIN-GUIDE.md`, `docs/ARCHITECTURE.md`. Тестови команди: `node scripts/verify-cms.mjs` и `node scripts/verify.mjs`.

Важно: този архив съдържа **изходния проект**, а не вече публикуван сайт. Тестовете и production build не бяха стартирани успешно в настоящата среда поради недостъпни npm зависимости. Няма реализирани онлайн плащания, поръчки или кухня.
